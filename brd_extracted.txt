Business Requirements Document (BRD)
MVP Digital Learn Platform
1. Ringkasan & Tujuan MVP
Digital Learn Platform MVP memungkinkan peserta belajar secara terstruktur lewat course dan modul,
mengikuti ujian, lalu memperoleh sertifikat digital yang keasliannya dapat diverifikasi.
MVP melayani dua sisi: User/Peserta dan Admin/Pengelola. Materi dibuka bertahap (progressive
learning): peserta harus menyelesaikan tahap sebelumnya sebelum lanjut ke tahap berikutnya.
MVP dibuat untuk memvalidasi proses pembelajaran digital dari awal sampai akhir:
Registration → Learning → Assessment → Certification → Verification

Tujuan MVP
1.​ Menyediakan pengalaman pembelajaran digital end-to-end.
2.​ Memungkinkan admin membuat dan mengelola course serta materi.
3.​ Memastikan peserta mengikuti materi secara berurutan.
4.​ Mengukur pemahaman peserta melalui ujian.
5.​ Menerbitkan sertifikat secara otomatis kepada peserta yang memenuhi persyaratan.
6.​ Menyediakan mekanisme verifikasi keaslian sertifikat.
7.​ Menyediakan monitoring dasar bagi admin terhadap aktivitas dan progress peserta.

Registration. Sistem memungkinkan user membuat akun.

Data: nama lengkap, email, password, konfirmasi password.
Email harus unik.
Password harus memenuhi minimum security requirement.
User menyetujui terms/privacy policy apabila diberlakukan.

Login. User login dengan email dan password. Sistem menyediakan forgot password, reset password,
dan logout.
User Profile. User dapat melihat dan mengubah data profil: nama lengkap, email, dan foto profil. Nama

Course Catalog. User dapat melihat daftar course yang tersedia dan membuka halaman detail sebelum

Course Detail. Halaman detail menampilkan judul, deskripsi, tujuan pembelajaran, instructor/pengelola,
daftar modul, jumlah modul, estimasi durasi, informasi ujian, dan informasi sertifikat. Modul yang belum
dapat diakses ditampilkan sebagai locked.
Enrollment. User dapat mendaftarkan diri ke course. Setelah enrollment berhasil, Module 1 terbuka
(unlocked).

5. Pembelajaran Bertahap
Learning Module. Course terdiri dari satu atau lebih modul. Setiap modul memiliki judul, deskripsi,
urutan, materi, durasi, dan status completion. Jenis materi MVP: video, PDF/document, dan text/article.
Material Pop-up Quiz. Sistem menampilkan pop-up quiz pilihan ganda pada titik (checkpoint) yang
ditentukan admin di dalam sebuah materi. Satu materi dapat memiliki lebih dari satu pop-up quiz.
Pop-up tidak dapat ditutup atau dilewati tanpa menjawab dengan benar.
Progressive Learning. Modul dibuka bertahap. Setelah Module 1 selesai, Module 2 terbuka; modul lain
tetap locked.

6. Ujian & Sertifikat
Final Examination. Setelah seluruh modul selesai, user dapat mengikuti ujian akhir pilihan ganda. Ujian
memiliki judul, daftar soal, durasi pengerjaan, pilihan jawaban, jawaban benar, passing grade, dan
jumlah attempt.
Examination Rules. Admin menentukan passing grade, jumlah soal, durasi pengerjaan, dan jumlah
kesempatan ujian/attemp. Jika waktu habis, sistem otomatis mengakhiri dan mengumpulkan ujian.
Peserta dinyatakan lulus apabila nilai mencapai atau melebihi passing grade sesuai attemp yang dimiliki.
Nilai yang diambil adalah nilai attemp tertinggi.
Contoh:
Durasi: 30 menit
Passing grade: 70
Maximum attempt: 3 kali
Attempt 1 → Score 60 → Failed
Attempt 2 → Score 65 → Failed
Attempt 3 → Score 80 → Passed → Certificate
Examination Result. Setelah ujian selesai, user melihat nilai, status kelulusan, jumlah benar, jumlah
salah, dan waktu pengerjaan (jika digunakan). Contoh: skor 85 dengan passing 70 berstatus PASSED dan
sertifikat langsung tersedia.
Certificate Generation. Sertifikat diterbitkan otomatis apabila user menyelesaikan seluruh modul dan
lulus ujian. Informasi sertifikat: nama peserta, nama course, nama penerbit, tanggal penerbitan,
Certificate ID, QR Code, dan Verification URL.
Certificate ID. Setiap sertifikat memiliki ID unik, misalnya DL-2026-000001. ID tidak boleh sama antar
sertifikat dan menjadi identifier untuk verifikasi.

Certificate Verification. Pihak lain dapat memverifikasi sertifikat tanpa login.
•​ Jika valid, halaman menampilkan: valid certificate, nama peserta, nama course, tanggal
penerbitan, Certificate ID, dan penerbit.
•​ Jika tidak valid, halaman menampilkan: Certificate not found / invalid certificate.

Course Management. Admin dapat create, view, edit, publish, unpublish, dan archive course. Status
course: Draft → Published → Archived. Course hanya dapat diikuti user apabila berstatus Published.
Module Management. Admin dapat create, edit, dan delete module, mengatur urutan module,
menambahkan materi, dan mengatur completion requirement. Contoh urutan: Introduction, Basic
Concept, Case Study, Exercise, Final Assessment.
Material Management. Admin dapat upload video, upload PDF/document, membuat text content,
mengedit dan menghapus material, serta mengatur urutan material. Status materi: Draft atau Published.

Examination Management. Admin dapat membuat ujian, menambah, mengubah, dan menghapus soal,
menentukan jawaban benar, mengatur passing grade, mengatur durasi pengerjaan, dan mengatur
jumlah attempt.
Pop-up Quiz Management. Admin dapat mengatur (menambah/menghapus/mengedit) pop-up quiz
pada setiap materi dan mengatur attemp.
Participant Monitoring. Admin melihat progress peserta, dengan filter berdasarkan course, peserta,
status, progress, nilai seluruh attemp, dan status sertifikat (-/Issued)

8. Non-Functional Requirements
Aspek

Requirement

Security

Password memakai secure hashing; role-based access; module locked tidak
dapat diakses lewat URL/API langsung; hasil ujian tidak dapat diubah lewat
client-side manipulation;

Performance

Login, course browsing, loading material, progress update, exam submission,
dan certificate generation berjalan dengan response time yang dapat diterima
pada kondisi normal

Availability

Platform dapat digunakan online sesuai target availability yang ditetapkan
untuk MVP

Scalability

Desain memungkinkan penambahan jumlah user, course, module, material,
exam, dan certificate tanpa perubahan fundamental pada core system
